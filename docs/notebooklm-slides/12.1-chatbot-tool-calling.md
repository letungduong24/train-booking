# Slide 12.1 - AI Chatbot with Tool Calling

## Slide Title
Trợ lý AI tra cứu dữ liệu thật bằng tool calling

## NotebookLM Instruction
Explain the chatbot as a controlled AI assistant. Keep this slide focused on concept and available tools. Use slide 12.2 for implementation flow.

## Main Slide Content
- Chatbot dùng Vercel AI SDK và Groq model.
- System prompt quy định rõ:
  - tìm chuyến phải dùng tool;
  - xem vé/ví cần đăng nhập;
  - thiếu thông tin thì hỏi lại.
- Tools chính:
  - `findStationByName`;
  - `searchTrainTrips`;
  - `getMyBookings`;
  - `getWalletBalance`;
  - `getPassengerGroups`;
  - `getRoutes`.
- Có direct train search path: khi câu hỏi đã đủ ga đi, ga đến và ngày, backend tự gọi tool tìm chuyến để giảm phụ thuộc vào suy luận của LLM.
- Hỗ trợ tiếng Việt không dấu/sai dấu bằng normalization.

## Speaker Notes
Điểm cần nói: chatbot không tự bịa lịch tàu. Nó gọi chính service tìm chuyến của hệ thống. Điều này làm câu trả lời bám dữ liệu thật và phù hợp với đồ án.

## Visual Suggestion
- Flow: User message -> intent/date/station parsing -> tool call -> database/service -> chat result.
